# Introduction

This project marks my first step into web development, where I learned the fundamental concepts of HTML and the basics of Git and GitHub. 

I explored the structure of a standard HTML document, including the HTML boilerplate, the purpose of the `<!DOCTYPE html>` declaration, and the roles of HTML elements and tags in creating and organizing web content.

I also gained practical experience with Git basics, including creating repositories, tracking changes, and managing project files. 

Through this project, I developed a foundational understanding of how web pages are structured and how version control helps organize and manage code. 

These skills provide a strong foundation for learning more advanced web development concepts and building interactive websites in the future.
